# Todo App

这是一个简单的待办事项应用，适合新手学习 HTML、CSS 和 JavaScript。

## 功能

- 添加待办事项
- 标记已完成/未完成
- 删除待办事项
- 使用浏览器本地存储保存数据

## 运行方式

1. 先确保本地有浏览器。
2. 下载或克隆这个项目。
3. 在项目根目录中，直接双击 `index.html` 打开即可。

如果你使用 VS Code，可以安装 Live Server 扩展，然后右键 `index.html` -> Open with Live Server。

## 项目结构

```text
todo-app/
├── index.html
├── style.css
├── script.js
├── README.md
```

## 学习建议

建议按下面顺序看：

1. 先看 `index.html`：理解页面结构
2. 再看 `style.css`：理解样式如何让页面更好看
3. 最后看 `script.js`：学习如何让页面有交互

## 下一步扩展

你可以继续扩展这些功能：

- 清空已完成任务
- 按优先级排序
- 编辑已有任务
- 使用数据库保存任务
- 改成 React / Vue 版本

## 说明

这是一个适合入门的项目，重点是理解前端开发的基本流程，而不是一开始就做特别复杂的功能。
